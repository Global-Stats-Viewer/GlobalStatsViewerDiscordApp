# GlobalStatsViewerPublicBot
Public repository for the Global Stats Viewer Discord Application, built off of [globalstatsviewer.com](https://globalstatsviewer.com/)
## Info Commands
### /about
Provides information about the Global Stats Viewer project, bot version, sources, and a link to the Discord server
### /ping
Lets you know the time between sending a command and recieving a result
### /staff-list
Provides the usernames of the staff members on the Global Stats Viewer team
## Profile Viewing Commands
### /profile
Lets the user view the GSV profile of any GSV, Discord, GD, AREDL, Pointercrate, or Pemonlist ID
### /completions
Lets the user view completions of any searched profile, can be toggled to be Classic or Platformer completions
